사용방법 안내

문맥 단어왕은 학생들이 문장과 문단 속에서 낱말의 뜻을 파악하는 연습을 할 수 있도록 만든 교육용 웹 애플리케이션입니다. 학생은 단계별 문제를 풀며 문맥 단서를 활용하는 방법을 익히고, 교사는 학생의 학습 결과를 확인하여 보충 지도에 활용할 수 있습니다.

본 서비스는 교사가 교육 활동을 지원하기 위해 개발한 무료 학습지원 웹앱입니다. 학생은 교사가 안내한 계정으로 로그인하여 사용합니다.

1. 접속 방법

  1. 웹브라우저에서 문맥 단어왕 주소에 접속합니다.
  2. 학생은 교사가 안내한 학생 계정으로 로그인합니다.
  3. 교사는 Google 계정으로 로그인하여 학생 계정과 학습 결과를 관리할 수 있습니다.

2. 학생 로그인 방법

  1. 첫 화면에서 학생 로그인 영역을 확인합니다.
  2. 교사가 안내한 학생 ID와 비밀번호를 입력합니다.
  3. 로그인 후 학습 단계 또는 문제 풀이 화면으로 이동합니다.
  4. 계정 정보는 다른 학생에게 알려주지 않습니다.

3. 학생 주요 기능

연습 1단계

한 문장을 읽고 밑줄 친 낱말의 뜻을 문맥으로 파악합니다. 낱말만 따로 외우는 것이 아니라 문장 속 단서를 찾아 뜻을 고르는 연습을 합니다.

연습 2단계

여러 문장이나 짧은 글을 읽고 알맞은 낱말 뜻을 고릅니다. 앞뒤 문장의 내용을 연결하여 낱말의 뜻을 추론하는 힘을 기릅니다.

연습 3단계

낯선 낱말이 나왔을 때 문맥 단서를 활용하여 뜻을 추측합니다. 정답을 고른 뒤에는 자신의 선택이 문맥과 잘 맞는지 확인합니다.

오답 복습

틀린 문제를 다시 확인하고 복습합니다. 어떤 문맥 단서를 놓쳤는지 살펴보며 다시 풀 수 있습니다.

오늘의 도전

정해진 문제를 풀고 오늘의 학습 결과를 확인합니다. 문제 풀이 결과는 학습 기록으로 저장될 수 있습니다.

단어왕 랭킹

오늘 또는 이번 주의 학습 결과를 확인할 수 있습니다. 랭킹은 학생들이 자신의 학습 참여를 돌아보는 참고 자료로 활용됩니다.

4. 교사 기능

  • 교사는 Google 계정으로 로그인합니다.
  • 학생 계정을 생성하고 관리할 수 있습니다.
  • 학생별 문제 풀이 결과와 학습 현황을 확인할 수 있습니다.
  • 정답 수, 오답 기록, 학습 단계 결과를 바탕으로 보충 지도에 활용할 수 있습니다.

5. 학습 결과 저장

학생이 문제를 풀면 학습 단계, 전체 문제 수, 정답 수, 오답 정보, 학습 활동 기록 등이 Firebase에 저장될 수 있습니다. 저장된 정보는 교사가 학생의 학습 상태를 파악하고 지도하는 데 활용됩니다.

6. 이용 시 주의사항

  • 다른 사람의 계정으로 로그인하지 않습니다.
  • 자신의 ID와 비밀번호를 다른 사람에게 알려주지 않습니다.
  • 학습 목적에 맞게 사용합니다.
  • 문제가 정상적으로 보이지 않거나 결과가 저장되지 않으면 교사에게 알립니다.
  • 개인정보처리방침과 이용약관을 확인한 뒤 서비스를 이용합니다.

7. 문의

서비스 이용 중 문제가 발생하면 담당 교사 또는 학교가 안내한 공식 문의 경로를 통해 문의합니다.
